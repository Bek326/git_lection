git - система контроля версий 
github - платформа для хранения git repositories и совместной работы

git init - инициализация git system
git add filename/dirname - добавление изменений в список для сохранения (staging area)
git status - проверка статуса (checkpoint)
git commit -m 'comment - сохранение версии (checkpoint)
git push - добавление изменений в github
git pull - стягивание изменений с github
git branch - просмотр текущей ветки
git branch branch_name - создание ветки
git checkout branch_name - переход к ветке
pull request/merge request - объеденение изменений веток
git clone - клонирование проекта
